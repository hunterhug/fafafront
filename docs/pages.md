## SEO 地址与节点隐藏（2026-09-15）

- **地址规则**：节点页 `/u/:name/node/:nodeSeo`，文章页 `/u/:name/node/:nodeSeo/:seo`。
  地址里不出现数字 id；`/u/:name/content/:seo` 与 `/content/:id` 两个旧路由已删除，落到 404 页。
- **SEO 由系统生成**：新建文章/节点时预填 8 位随机短码（可改）。唯一范围：节点 SEO 在同一用户内唯一，
  文章 SEO 在所属节点内唯一。个人中心的 SEO 输入框旁有 `?` 说明规则。
- **节点隐藏**：内容管理节点树的「隐藏/显示」；隐藏后该节点及其子节点下的文章不再出现在首页、
  发现页与他人主页，作者本人仍可见（卡片标「已隐藏」），文章直链仍可打开。管理后台节点管理也有
  隐藏/显示操作（任意用户）。
- **节点页两种视角**：作者本人访问自己的隐藏节点能看到文章并看到「已隐藏」提示；其他人访问同一地址
  提示「该节点不存在或已隐藏」。旧的 `?node=<id>` 参数会被清掉。
- **文章数口径**：个人主页头部的文章数 = 当前访问者能看到的篇数（作者本人看自己的主页是总数）。

## 站点品牌与站点设置（2026-09-15）

- 站点标题、副标题、社区介绍、页脚介绍都来自后端站点设置（公开接口 `/app/site/config`，管理后台
  「站点设置」可改）。首页标题为「站点标题 - 站点副标题」，其它页面标题为「页面名 - 站点标题」。
- 首页「社区公告」与发现页显示「站点标题 + 社区介绍」；页脚显示页脚介绍。
- `index.html` 里的 `<title>` 是**静态默认值**，页面加载后由站点设置覆盖；改后台设置不会改源文件。
- 页头 Logo 为猫爪图形（`components/SiteLogo.vue`），favicon 为 `public/favicon.svg`。
- 文章页右侧目录（正文 > 2000 字才显示）在长文下会跟随高亮自动滚动，始终显示当前章节。

## 个人主页节点交互（2026-08-29）

- 一级节点与「推荐/最新」**同级**，作为顶部 tab 横向排列。
- 选中一级节点后，展示**二级子节点**子 tab（「全部」+ 各子节点）。
- 「全部」= 该一级节点及其二级子节点的文章（后端 `include_children=true` 下钻）。
- 选中某子节点 = 仅该子节点的文章。
- 文章卡片上的节点名点击可跳转到对应节点 tab。

## 写文章/编辑文章（全屏，2026-08-31 飞书文档式）

- 编辑器为**全屏覆盖层**（Teleport 到 body），**无工具栏**纯净界面，正文区 1240px 宽居中（飞书式满宽体验）。
- 正文为 **wangEditor 5 所见即所得**（无工具栏），存储仍是 Markdown（turndown 保存 / markdown-it 加载），支持：
  - **Markdown 快捷输入**：`#` 标题、`-` 列表、`>` 引用、`---` 分割线、``` 代码块、表格、`- [ ]` 待办
  - **粘贴自动转换**：粘贴含 Markdown 语法的文本自动转成格式化内容
  - **右键菜单**：选中文本→格式（加粗/斜体/下划线/删除线/行内代码/链接/引用/清除格式）；空白→插入（标题/列表/待办/引用/代码/分割线/表格/图片/视频）
  - **hoverbar 浮条**（选中文本）：加粗/斜体/下划线/删除线/行内代码/文字颜色/背景高亮/清除格式/链接/引用（10 项）
  - **斜杠 `/` 菜单**（12 项）：行首输入 `/` 弹出，即时过滤 + 键盘导航（↑↓/Enter/Esc），分组（基础/插入）；移动端有悬浮 **+** 按钮唤起同一菜单
  - **段落 hover 块操作**：左侧 **+**（插入段落）与 **≡** 手柄（拖拽排序）
  - **插入能力**：表格、图片（上传至 /api/file/upload）、视频（mp4/iframe）、链接、待办事项、表情面板（24 emoji）
  - **代码块语言标签**：右上角显示语言名
  - **字数统计**：右下角「n 字」
  - **自动保存**：停止输入 1.5s 防抖自动保存（Notion/Google Docs 式），右上角显示「已自动保存 HH:MM」
  - **快捷键**：Ctrl/Cmd+S 保存；标题 Enter 直接进入正文；Ctrl+Z/Y 撤销重做；Tab 列表缩进
- 编辑模式工具栏：返回（未保存确认）/ 版本与草稿状态 / 历史版本 / 保存草稿 / 发布（成功弹窗可跳转查看）。
- **文档大纲**：长文（≥2 标题）右侧悬浮目录，点击滚动定位（视口 ≤1480px 隐藏）。
- 移动端：标题 24px、空文档提示居中、悬浮 **+** 插入按钮、hoverbar 窄屏滚动防护，无横向溢出。
